# Проверка лабораторных 7 и 8

Дата: 22 ноября 2026 года.

## Лабораторная 7

Исходный проект `web7` сопоставлен с `methodical/Ch7.odt`.

| Раздел | Реализация |
| --- | --- |
| 7.1 | `show`, поиск пользователя по ID, профиль, Gravatar с параметром size, debug только в development |
| 7.2 | `form_with(model: @user)`, имя, email, пароль и подтверждение |
| 7.3 | strong parameters, валидации, partial ошибок, повторный вывод формы с HTTP 422 |
| 7.4 | сохранение пользователя, перенаправление на профиль, flash и интеграционные тесты |
| 7.5 | настройки HTTPS, Puma и PostgreSQL присутствуют; развёртывание на хостинге не подтверждено |

Тесты исходного `web7`: 30 тестов, 103 проверки, без ошибок и падений.
Основной итоговый код соответствует главе 7. Упражнения с отладчиком,
временными изменениями кода и личным Gravatar не подтверждаются одной
проверкой итоговых файлов. Текущий `web7` не изменялся.

## Лабораторная 8

`web8` создан как отдельный репозиторий на основе истории `web7`.

| Раздел | Реализация |
| --- | --- |
| 8.1 | `GET /login`, `POST /login`, `DELETE /logout`, SessionsController, форма с `scope: :session`, поиск по email в нижнем регистре и `authenticate` |
| 8.1.4–8.1.5 | `flash.now[:danger]`, ответ 422, проверка исчезновения ошибки на следующем запросе |
| 8.2.1–8.2.2 | SessionsHelper подключён к ApplicationController, `log_in`, `current_user`, `logged_in?`, сброс сессии перед входом |
| 8.2.3–8.2.5 | навигация по состоянию входа, меню Account, Importmap, JavaScript, мобильное меню и стили footer |
| 8.2.6 | `User.digest`, fixture с bcrypt, тесты входа и навигации, отдельная проверка неверного пароля при существующем email |
| 8.2.7 | автоматический вход после регистрации со сбросом предыдущей сессии |
| 8.3 | сброс сессии и текущего пользователя, переход на главную с HTTP 303, проверки выхода |

Переключение меню реализовано через делегирование событий: отсутствующий
Account у гостя не вызывает ошибки, переходы Turbo не дублируют обработчики.
Перед сохранением страницы в кэш Turbo меню закрываются.
Атрибуты `aria-expanded` обновляются при раскрытии меню.

Проверки: 38 тестов, 162 проверки, без ошибок, падений и пропусков;
RuboCop проверил 51 файл без замечаний; Dart Sass собрал стили.

В браузере на локальном сервере проверены регистрация, автоматический вход,
Account, выход, повторный вход с email в верхнем регистре и раскрытие
мобильного меню и Account при ширине 390 пикселей.

Ссылки Users и Settings оставлены заглушками согласно главе 8.
Развёртывание на хостинге не выполнялось. Закрытие браузера и удаление
cookie вручную не проверялись; используется обычная временная Rails-сессия.
